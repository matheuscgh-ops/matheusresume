# Matheus Barbosa — Portfolio

Personal portfolio site (English / Portuguese). Single static `index.html`, no build step.

- English by default; the EN/PT toggle remembers the choice.
- Link straight to Portuguese with `#pt` at the end of the URL.

## Publish with GitHub Pages

1. Create a repo (e.g. `portfolio`) and push these files to `main`.
2. Repo **Settings → Pages → Source: Deploy from a branch → `main` / root**.
3. The site goes live at `https://<username>.github.io/portfolio/`.

To serve it at `https://<username>.github.io/`, name the repo `<username>.github.io` instead.
